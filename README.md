## ⚡ Sobre o Projeto

O portfólio foi desenhado com uma estética de **Terminal/Hacker**, refletindo meu foco e paixão por infraestrutura, segurança e back-end. Ele não é apenas estático; o projeto consome dados dinamicamente, garantindo que meus projetos mais recentes estejam sempre atualizados sem necessidade de manutenção manual.

### 🎯 Funcionalidades Principais

- **Interface Terminal-Like:** Design responsivo focado em usabilidade, com overlay de *scanlines*, animações de digitação (typing effect) e suporte nativo a *Light/Dark Mode*.
- **Integração Automática (GitHub API):** Uma arquitetura híbrida (REST + GraphQL) que busca automaticamente meus repositórios fixados (pinned) e os complementa com os repositórios públicos mais recentes.
- **Sistema de Proficiência em Nodes:** Exibição de *skills* através de "blocos de memória" animados, fugindo das clássicas e subjetivas barras de porcentagem.
- **Gestão de Experiência e Certificações:** Seções dedicadas à minha trajetória acadêmica e profissional (GovTech, Inovação, Cybersecurity).

## 🛠️ Tecnologias Utilizadas

Este portfólio foi construído do zero, priorizando performance e código limpo, sem frameworks JavaScript pesados no front-end:

* **Markup & Estilo:** HTML5, CSS3 (Custom Properties, Flexbox, CSS Grid, Animações Keyframe)
* **Lógica & Integração:** Vanilla JavaScript (ES6+), Fetch API, Promises, Async/Await
* **UI/UX & Ícones:** Bootstrap 5.3 (apenas o grid system e utilities básicos), Devicon
* **Deploy:** Vercel
